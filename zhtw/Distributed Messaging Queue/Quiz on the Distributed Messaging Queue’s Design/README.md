# Answers on the Distributed Messaging Queue’s Design (分佈式消息隊列設計的答案)
```
1. 死信隊列包含什麼樣的消息？(B)

A)
已成功消費的消息。

B)
未能消費並已達到最大嘗試次數限制的消息。

Explanation
解釋
由於缺乏適當的指示，無法投遞或退回死信。同樣，以死信命名的隊列包含那些在達到最大嘗試次數限制後未能被消費的消息。

C)
由現在已死亡的進程生成的消息。

D)
以上都不是
```

```
2. 在多個伺服器上複製隊列的目的是增強系統的 _________。(C)

A)
安全性

B)
一致性

C)
可用性

Explanation
解釋
在多個節點上複製隊列和相應消息的目的是提高系統的可用性。當一個節點宕機時，另一個備用伺服器可以為請求提供服務。

D)
以上都不是
```

```
3. 在獨立主機集群模型中，哪個組件負責在其他節點中複製消息？(C)

A)
前端伺服器

B)
集群管理器

C)
集群內的任何隨機主機

Explanation
解釋
在獨立主機集群模型中，隨機主機可以接收負責在各個隊列中的其他主機中複製消息的消息。

D)
以上都不是
```

```
4. 元資料服務的目的是 _________。(B)

A)
將消息及其元資料一起存儲在隊列中

B)
在元資料存儲和快取中存儲、檢索和更新隊列的元資料

Explanation
解釋
元資料服務充當前端和元資料存儲 (及快取) 之間的中間件。它負責在元資料存儲和快取中存儲、檢索和更新隊列的元資料。

C)
提供訪問隊列的安全功能

D)
以上都不是
```

```
5. 以下哪項負責對隊列進行分區並為每個分區分配主節點？(A)

A)
內部集群管理器

Explanation
解釋
內部集群管理器將隊列分成多個部分，並為每個分區分配一個主節點。相比之下，外部集群管理器為每個隊列分區分配集群。

B)
外部集群管理器

C)
主節點

D)
輔助節點之一
```
