# System Design: Yelp (系統設計：Yelp)
## What is Yelp? (什麼是 Yelp？)
Yelp 是一個一站式平台，供消費者發現、連接並與當地商家進行交易。有了它，使用者可以輕鬆地加入等候名單、進行預訂、安排約會或購買商品。Yelp 還提供有關當地商家的資訊、照片和評論。

使用者提供地名或其 GPS 位置，系統會查找附近的地方。使用者還可以在此平台上以文字、圖片的形式上傳他們的意見，或對他們訪問過的地方進行評級。其他基於位置的服務包括 Foursquare 和 Google Nearby。

基於鄰近伺服器的服務有助於查找附近的景點，如餐館、劇院或休閒場所。設計這樣一個系統具有挑戰性，因為我們必須以最小的延遲有效地找到給定半徑內的所有可能地點。這意味著我們必須縮小世界上所有地點的範圍 (可能有數十億個)，並且只查明相關的地點。
