Answers (答案)

```
1 (選擇所有適用項。) 如果我們不限制片段數量以減少圖表大小，哪個需求將無法滿足？

Selected Option (選擇的選項)
Availability (可用性)

Explanation (解釋)
查詢將更慢地返回結果，影響使用者響應時間。

Consistency (一致性)

Selected Option (選擇的選項)
Scalability (可擴展性)

Explanation (解釋)
修改一個巨大的圖表並不容易。

Reliability (可靠性)
```

```
2 (對或錯) 分區類型 (基於區域或 PlaceID) 會影響四元樹的結構。

Correct Answer (正確答案)
True (對)

Explanation (解釋)
是的，因為我們無法保證每個片段中都有相同數量的地點。雖然這不會成為問題，因為我們將在定義的半徑內找到我們的相鄰片段。

False (錯)
```

```
3 如果我們使用領導者-追隨者方法來幫助我們進行複製，在哪種情況下響應時間延遲的機會更大？

A)
當領導者異步更新追隨者時

Explanation (解釋)
領導者不會等到所有追隨者都更新了資料，它會更新其存儲中的資料，然後將更新發送給追隨者。

Correct Answer (正確答案)
B)
當領導者同步更新追隨者時

Explanation (解釋)
領導者等到所有追隨者都更新了資料。

C)
當領導者保存一天的更新並每天向追隨者發送一次更改時

Explanation (解釋)
領導者不會要求追隨者立即更新資料，因此不會有延遲。
```

```
4 (選擇所有適用項。) 如果領導者和追隨者同時死亡會發生什麼？

Selected Option (選擇的選項)
A)
我們將不得不重建四元樹。

Explanation (解釋)
我們將不得不從保存它們的鍵值存儲中重建四元樹。

Selected Option (選擇的選項)
B)
效能將受到影響。

Explanation (解釋)
我們將無法為任何使用者查詢提供服務，這將影響效能。

Selected Option (選擇的選項)
C)
可用性將受到影響。

Explanation (解釋)
領導者和追隨者都將宕機，因此他們將無法處理請求。
```
