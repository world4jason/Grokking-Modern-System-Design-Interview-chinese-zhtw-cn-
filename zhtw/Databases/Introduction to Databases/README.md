# Introduction to Databases (資料庫簡介)
## Problem statement (問題陳述)
讓我們從一個簡單的問題開始。我們能在不使用資料庫的情況下製作軟體應用程式嗎？假設我們有一個像 WhatsApp 這樣的應用程式。人們使用我們的應用程式與朋友交流。現在，我們可以在哪裡以及如何永久儲存資訊 (人名及其相應訊息的列表) 並檢索它？

我們可以使用一個簡單的檔案在單獨的行上儲存所有記錄，並從同一個檔案中檢索它們。但是使用檔案進行儲存有一些局限性。

### Limitations of file storage (檔案儲存的局限性)
我們無法為從不同位置存取儲存檔案的單獨使用者提供併發管理。

我們無法向不同的使用者授予不同的存取權限。

當新增數千個條目時，系統將如何擴展和可用？

我們如何在短時間內為不同的使用者搜尋內容？
[檔案儲存的局限性](./file.jpg)

### Solution (解決方案)
可以使用資料庫解決上述限制。

資料庫 (database) 是易於管理和存取的有組織的資料集合。建立資料庫是為了更容易地存取、檢索、修改和刪除與不同資料處理過程相關的資料。

我們使用資料庫管理的一些應用程式是銀行系統、線上商店等。不同的組織根據其需求擁有不同大小的資料庫。

注意：根據 https://www.comparebusinessproducts.com/，世界氣候資料中心 (WDCC) 是世界上最大的資料庫。它包含大約 220 TB 的 Web 資料和 6 PB 的附加資料。
有兩種基本類型的資料庫：
SQL (關聯式資料庫)
NoSQL (非關聯式資料庫)
它們在預期用例、保存的資訊類型和採用的儲存方法方面有所不同。

[SQL 與 NoSQL](./db_type.jpg)

關聯式資料庫，就像記錄聯絡號碼和地址的電話簿一樣，是有組織的並且具有預定的模式。非關聯式資料庫，就像儲存從個人恆定資訊到購物偏好的任何內容的檔案目錄一樣，是非結構化的、分散的，並具有動態模式。我們將在下一課中詳細討論它們的區別和類型。

## Advantages (優點)
適當的資料庫對於每個企業或組織都是必不可少的。這是因為資料庫儲存了有關組織的所有基本資訊，例如人員記錄、事務、薪資資訊等。以下是資料庫重要的一些原因：

Managing large data (管理大數據)：使用資料庫可以輕鬆處理大量資料，這對於使用其他工具來說是不可能的。

Retrieving accurate data (data consistency) (檢索準確資料 (資料一致性))：由於資料庫中的不同約束，我們可以隨時檢索準確的資料。

Easy updation (易於更新)：使用資料操縱語言 (DML) 可以很容易地更新資料庫中的資料。

Security (安全性)：資料庫確保資料的安全性。資料庫只允許授權使用者存取資料。

Data integrity (資料完整性)：資料庫通過使用不同的資料約束來確保資料完整性。

Availability (可用性)：資料庫可以在不同的伺服器上複製 (使用資料複製)，這些伺服器可以同時更新。這些副本確保了可用性。

Scalability (可擴展性)：資料庫被劃分 (使用資料分區) 以管理單個節點上的負載。這增加了可擴展性。
