# System Design: Newsfeed System (系統設計：動態消息系統)

## What is a newsfeed? (什麼是動態消息？)
任何社交媒體平台 (Twitter、Facebook、Instagram) 的動態消息都是由使用者關注的實體生成的故事列表。它包含文字、圖片、影片和其他活動，如按讚、評論、分享、廣告等等。此列表不斷更新並在使用者主頁上呈現給相關使用者。同樣，動態消息系統也會向使用者顯示來自朋友、關注者、群組和其他頁面的動態消息，包括使用者自己的貼文。

```
實體可以是頁面、群組、朋友和使用者的關注者。
```

動態消息對社交媒體平台使用者至關重要，因為它讓他們了解最新的行業發展、時事和相關資訊。它還為他們提供了定期返回並連接平台的額外理由。數十億使用者使用此類平台。具有挑戰性的任務是實時提供個性化的動態消息，同時保持系統的可擴展性和高可用性。

本章將討論像 Facebook、Twitter、Instagram 等社交平台的動態消息系統的高層和詳細設計。

## How will we design the newsfeed system? (我們將如何設計動態消息系統？)
我們將動態消息系統的設計分為以下三節課：

1. **Requirements (需求)**：在本課中，我們將確定功能和非功能需求。我們還將估算每天為數十億使用者提供個性化動態消息所需的資源需求。
2. **Design (設計)**：我們將在本課中討論動態消息系統的高層和詳細設計。我們還將描述我們提議設計的 API 設計和資料庫模式。此外，本課還將幫助我們對動態消息進行排名，以提供更好的使用者體驗。
3. **Evaluation (評估)**：在本課中，我們將根據非功能需求評估動態消息系統的設計。我們還將進行測驗，以評估我們對動態消息系統設計的理解。
