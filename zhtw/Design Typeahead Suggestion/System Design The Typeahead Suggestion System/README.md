# System Design: The Typeahead Suggestion System (系統設計：預輸入建議系統)

## Introduction (介紹)
Typeahead suggestion (預輸入建議)，也稱為 autocomplete (自動完成) 功能，使用戶能夠搜尋已知且頻繁搜尋的查詢。當使用者在搜尋框中鍵入查詢時，此功能即開始發揮作用。預輸入系統根據使用者的搜尋歷史、當前搜尋的上下文以及不同使用者和地區的趨勢內容，提供一系列建議來完成查詢。頻繁搜尋的查詢總是出現在建議列表的頂部。預輸入系統不會讓搜尋更快。但是，它可以幫助使用者更快地組成句子。它是所有搜尋引擎中增強使用者體驗的重要組成部分。

## How will we design a typeahead suggestion system? (我們將如何設計預輸入建議系統？)
我們將關於預輸入建議系統設計的章節分為六課：

1. **Requirements (需求)**：在本課中，我們將重點關注設計預輸入建議系統的功能和非功能需求。我們還將討論系統平穩運行的資源估算。
2. **High-level design (高層設計)**：在本課中，我們討論我們的預輸入建議系統版本的高層設計。我們還討論了設計中使用的一些基本 API。
3. **Data Structure for Storing Prefixes (儲存前綴的資料結構)**：在本課中，我們將介紹一種稱為 trie (字典樹) 的高效樹形資料結構，用於存儲搜尋前綴。我們還將討論如何進一步優化它以減少樹遍歷時間。
4. **Detailed design (詳細設計)**：在本課中，我們解釋了兩個主要組件：suggestions service (建議服務) 和 assembler (組裝器)，它們構成了預輸入建議系統的詳細設計。
5. **Evaluation (評估)**：本課根據系統的非功能需求評估預輸入建議系統的提議設計。它還提供了一些客戶端優化和個性化，這些可能會顯著影響系統的設計。
6. **Quiz (測驗)**：在本課中，我們通過測驗評估我們對設計的理解。
