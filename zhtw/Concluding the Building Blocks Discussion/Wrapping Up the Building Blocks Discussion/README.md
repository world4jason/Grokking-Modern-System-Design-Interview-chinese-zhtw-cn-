# Wrapping Up the Building Blocks Discussion (總結構建塊討論)

我們已經涵蓋了相當數量的構建塊，這將使我們能夠解決更大的設計問題。在接下來的章節中，我們將解決各種將使用各種構建塊的問題。

由於我們已經涵蓋了構建塊，我們可以專注於解決更大的設計問題。從現在開始，我們將假設當我們在接下來的設計問題中使用所有討論過的構建塊時，您已經熟悉它們。

## What’s next? (接下來是什麼？)

我們將在接下來的章節中學習和探索十三個設計問題。我們將研究以下系統設計：

1. YouTube
2. Quora
3. Google Maps
4. Yelp
5. Uber
6. Twitter
7. Newsfeed
8. Instagram
9. TinyURL
10. Web Crawler
11. WhatsApp
12. Typeahead
13. Google Docs

這些設計中的每一個都是獨立的章節，但我們建議您按照指定的順序瀏覽這些章節。有些問題有背景資料，對其他設計問題很有幫助。例如，首先解決 Google Maps 問題可能對有興趣學習 Uber 設計問題的讀者有用。

在課程結束時，我們將以“Spectacular Failures (壯觀的失敗)”一章來總結我們的課程，我們將在其中討論一個小錯誤或失誤如何導致一些設計最成功的系統發生重大中斷或故障。
