```

A)
實時交通狀況

專業司機

車輛速度
```

```
3 (選擇所有適用的選項。) 我們可以在 CDN 中儲存什麼資訊？

A)

司機和乘客的個人資料詳情

C)
乘客的最後行程

D)

```

Answers (答案)

1. (A) (D)

```
2
(選擇所有適用的選項。) 為什麼在網約車服務設計中儲存路線資訊至關重要？

Selected
A)
它有助於優化 ETA。

Explanation
解釋
我們在資料庫中儲存​​了每條路線的實際值。下次有人選擇此路線時，我們可以提供更準確的 ETA。

Selected
B)
它最小化乘車費用波動。

Explanation
解釋
我們會根據乘車詳情了解路線詳情。因此，ETA 估算將接近實際花費的時間。這就是為什麼初始費用估算 (在乘車前確定) 波動較小的原因。

C)
它有助於確定司機的獎金。

Explanation
解釋
保存路線詳情不會影響獎金。相反，司機行駛的距離對確定獎金很重要。

D)
它有助於吸引更多乘客。
```

```
3
(選擇所有適用的選項。) 我們可以在 CDN 中儲存什麼資訊？

A)
司機的當前位置

Explanation
解釋
它會經常更換，所以不合適。

Selected
B)
司機和乘客的個人資料詳情

Explanation
解釋
姓名、司機照片、車輛詳細資訊等，可以儲存在 CDN 中。

Selected
C)
乘客的最後行程

Explanation
解釋
乘客的行程詳情可以儲存在 CDN 中，因為一旦行程結束，這些詳情就不會改變。

D)
交通詳情

Explanation
解釋
交通不一致。它每一秒都在變化。CDN 通常儲存不經常更改的靜態資料。
```
