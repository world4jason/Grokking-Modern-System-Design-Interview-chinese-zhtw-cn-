# System Design: Uber (系統設計：Uber)
## What is Uber? (什麼是 Uber？)
Uber 是一個為其使用者提供網約車服務的應用程式。任何需要乘車的人都可以註冊並預訂車輛以從起點前往目的地。任何擁有車輛的人都可以註冊為司機並將乘客送往目的地。司機和乘客可以通過智慧型手機上的 Uber 應用程式進行通訊。

## How will we design Uber? (我們將如何設計 Uber？)
關於 Uber 還有許多懸而未決的問題。它是如何工作的？司機如何與乘客聯繫？這只是眾多問題中的兩個。本章將設計一個像 Uber 這樣的系統並找到這些問題的答案。

我們將 Uber 的設計分為六個部分：

1. **Requirements (需求)**：本課將描述像 Uber 這樣的系統的功能和非功能需求。我們還將估算 Uber 多個方面的需求，例如儲存、頻寬和計算資源。
2. **High-level Design (高層設計)**：我們將在本課中討論 Uber 的高層設計。此外，我們還將簡要說明 Uber 服務的 API 設計。
3. **Detailed Design (詳細設計)**：我們將在本課中探討 Uber 的詳細設計。此外，我們還將討論用於設計 Uber 的不同組件的工作原理。
4. **Payment Service and Fraud Detection (支付服務和欺詐檢測)**：我們將了解支付系統在 Uber 設計中如何工作。此外，我們還將討論如何在類似 Uber 的系統中發現與支付相關的各種欺詐行為。
5. **Evaluation (評估)**：本課將解釋 Uber 如何通過擬議的設計滿足所有非功能需求。
6. **Quiz (測驗)**：我們將通過測驗來強化 Uber 設計的主要概念。
