### Advantages (優點)
網址縮短服務的主要優點是：

- 縮短的網址使用方便：由於其增強的可訪問性和不可破壞性，它們優化了跨不同形式設備的鏈接使用。
- 它們在視覺上很專業，引人入勝，並促進了更高程度的分享可能性。
- 它們在打字時不易出錯。
- 它們在使用者端需要更小的存儲空間。

### Disadvantages (缺點)
網址縮短服務也有一些相關的缺點。其中一些如下：

- 使用第三方服務生成的短網址會使我們失去品牌的原創性。許多使用相同服務的不同品牌會獲得包含相同域名的短網址。
- 由於我們使用第三方服務進行網址縮短，因此它始終存在關閉並清除我們所有縮短網址的可能性。
- 我們的商業品牌形象取決於網址縮短服務的可信度。錯誤的商業舉措可能會對我們的業務產生負面影響。獲取需求的自定義短網址的競爭非常激烈，因此當我們開始生成短網址時，最好的自定義網址可能已經被佔用了。

## How will we design a URL shortening service? (我們將如何設計網址縮短服務？)
我們將網址縮短服務設計分為以下五個課程：

1. **Requirements (需求)**：本課程討論網址縮短服務的功能和非功能需求，同時估算實現這些需求所需的資源。此外，它還列出了構建此類服務所需的基本構建塊。
2. **Design and Deployment (設計和部署)**：解釋了每個組件的工作和使用、它們之間的聯繫以及它們作為一個單元的整體工作機制。
3. **Encoder (編碼器)**：這門特定的課程揭開了設計中使用的編碼器的內部機制，說明了我們使用它的原因以及數學解釋。
4. **Evaluation (評估)**：最後，我們通過考慮設計需求的不同維度並包括改進它的可能性來測試我們的設計。
5. **Quiz (測驗)**：本課程將測試我們對 TinyURL 設計的理解。
