在本課程中，我們從基本構建塊 (基本的子系統結合以構成更大的系統) 的角度學習了系統設計活動。這樣做使我們能夠專注於特定的業務使用案例，而不是重複反復出現的概念。

我們從許多不同領域中仔細選擇了設計問題，並明確努力在每個問題中納入系統設計活動的一些獨特方面或問題。
