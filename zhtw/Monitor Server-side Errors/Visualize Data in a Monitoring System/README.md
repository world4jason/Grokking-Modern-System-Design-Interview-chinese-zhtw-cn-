# Visualize Data in a Monitoring System (在監控系統中可視化資料)
大型資料中心擁有數百萬台伺服器，可視化所有伺服器的健康資料具有挑戰性。監控一組伺服器的一個重要方面是知道哪些伺服器處於活動狀態，哪些伺服器處於離線狀態。現代資料中心可以在一座建築中容納數千台伺服器。我們可以使用熱圖在資料中心緊湊地顯示有關數千台伺服器的資訊。

熱圖是一種資料可視化技術，通過使用顏色在二維中顯示現象的大小。

## Using heat maps to troubleshoot (使用熱圖進行故障排除)
我們將使用熱圖識別伺服器是否宕機。每個伺服器機架都已命名，並按資料中心、集群、行排序，因此這些級別中常見的問題顯而易見。

描繪大量組件運行狀態的熱圖是一種有效的方法。每個組件的健康狀況由大矩陣中每個單元格的顏色指示。帶有綠色單元格的節點在允許的參數範圍內運行，而帶有紅色單元格的節點在多次嘗試後仍無響應。

下面，我們有一個顯示伺服器狀態的熱圖。

[使用熱圖查看資料中心中的伺服器](./cluster.jpg)

我們可以將熱圖用於全球分佈式系統，並持續共享伺服器的健康資訊。我們可以使用一位 (1 表示活動，0 表示死亡)。對於 1,000,000 台伺服器，我們有 125 KB 的資料。我們可以通過紅色快速找出哪個伺服器宕機，並專注於有問題的部分。

我們可以創建類似的熱圖，以鳥瞰任何資源，如文件系統、網絡交換機、鏈路等。

## Summary (總結)
- 監控系統在分佈式系統中至關重要，因為它們有助於分析系統並在出現問題時向利益相關者發出警報。

- 我們可以使用推送和拉取方法的混合使監控系統具有可擴展性。

- 熱圖是一種強大的可視化工具，有助於我們在緊湊的空間中了解數千台伺服器的健康狀況。
