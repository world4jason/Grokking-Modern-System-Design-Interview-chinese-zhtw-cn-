# System Design: Twitter (系統設計：Twitter)

Twitter 是一個免費的微部落格社交網路，註冊使用者可以在其中發布稱為“推文”的訊息。使用者還可以對公開推文進行按讚、回覆和轉發。截至 2021 年，Twitter 擁有約 3.97 億使用者，並且隨著時間的推移激增。其受歡迎的主要原因之一是在平台上廣泛分享突發新聞。另一個重要原因是 Twitter 允許我們與來自不同社區和文化的人互動並向他們學習。

## How will we design Twitter? (我們將如何設計 Twitter？)
我們將 Twitter 的設計分為四個部分：

1. **Requirements (需求)**：本課描述了 Twitter 的功能和非功能需求。我們還將估算 Twitter 的多個方面，例如儲存、頻寬和計算資源。
2. **Design (設計)**：在本課中，我們將討論 Twitter 的高層設計。我們還簡要解釋了 API 設計並確定了 Twitter 架構的重要組件。此外，我們將討論如何管理前 k 個問題，例如 Twitter 上數百萬使用者按讚或查看的推文。
3. **Client-side load balancers (客戶端負載平衡器)**：本課討論 Twitter 如何為其微服務系統執行負載平衡，以管理各種服務實例之間的數十億個請求。此外，我們還將了解為什麼 Twitter 使用定製的負載平衡技術而不是其他常用的方法。
4. **Quiz (測驗)**：最後，我們將通過測驗來加強 Twitter 設計的主要概念。
