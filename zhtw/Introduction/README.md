# What is system design? (什麼是系統設計？)

```
系統設計是定義組件及其集成、API 和資料模型以構建滿足特定功能和非功能需求集的大規模系統的過程。
```

系統設計使用計算機網絡、並行計算和分佈式系統的概念來構建擴展性好且性能高的系統。

               Computer (計算機)
               networking (網絡)
             /   System \ (系統)
            /    Design  \ (設計)
     Distributed--------Parallel (並行)
     Systems (分佈式系統)        Computing (計算)
```         
系統設計的目標是構建可靠、有效和可維護的系統，以及其他特徵。

```
• 可靠的系統處理故障、失敗和錯誤。
• 有效的系統滿足所有使用者需求和業務需求。
• 可維護的系統靈活且易於擴展或縮減。添加新功能的能力也屬於可維護性的範疇。
```

使用構建模組的現代系統設計。
