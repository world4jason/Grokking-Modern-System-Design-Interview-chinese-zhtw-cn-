# Answers (答案)
```
如果我們被要求設計 Netflix，以下哪一對需求是不能妥協的？

Correct Answer (正確答案)

Low latency and high availability (低延遲和高可用性)

Explanation (解釋)
流媒體服務非常需要這兩個設計目標來為最終使用者提供良好的 QoE。

Low latency and HD video (低延遲和高清影片)

Explanation (解釋)
即使影片質量不高，服務的可用性也非常重要

High availability and HD video (高可用性和高清影片)

Explanation (解釋)
這可能會導致緩衝和延遲問題。因此，需要低延遲。

Consistency and HD video (一致性和高清影片)

Explanation (解釋)
在流媒體服務方面，一致性並不是最具挑戰性或最理想的指標。

```
在向最終使用者流式傳輸方面，哪種編碼技術最有效？

A)
對所有類型的內容使用單一編碼技術以實現設計的簡單性。

Explanation (解釋)
根據影片中內容的類型，最好使用不同的編碼方案以獲得最佳結果。

B)
根據影片中的內容對整個影片進行編碼——例如，對具有動態色彩的動作電影和 2D 卡通進行不同的編碼。

Explanation (解釋)
對整個影片進行編碼有幫助，但這不是最佳解決方案。

Correct Answer (正確答案)
C)
對影片中的不同鏡頭或片段使用不同的編碼技術。例如，高動態場景的編碼應與單個影片中的較少動態場景不同。

Explanation (解釋)
使用逐個鏡頭的編碼技術可以節省儲存空間、傳輸頻寬，並使流式傳輸在使用者頻寬方面更加方便。

D)
編碼根本不重要。

Explanation (解釋)
這不是真的。編碼有助於整體優化。

Explanation (解釋)
不是最好的選擇，因為它需要 CDN 具有非凡的頻寬才能為 10 萬使用者中的每一個提供 1080p 質量的流媒體服務。

B)

Explanation (解釋)

D)

Explanation (解釋)
流媒體伺服器是主機託管站點的替代方案。對於同一地理位置內的 10 萬使用者來說，這些是不夠的。
