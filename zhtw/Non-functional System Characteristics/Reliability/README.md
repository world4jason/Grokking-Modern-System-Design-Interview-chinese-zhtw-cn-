# Reliability (可靠性)

## What is reliability? (什麼是可靠性？)

可靠性 R 是服務在指定時間內執行其功能的概率。R 衡量服務在不同操作條件下的表現。

我們通常使用平均故障間隔時間 (MTBF) 和平均修復時間 (MTTR) 作為衡量 R 的指標。

MTBF = 總經過時間 - 停機時間總和 / 故障總數

MTTR = 總維護時間 / 總維修次數

(我們爭取更高的 MTBF 值和更低的 MTTR 值。)

### Reliability and availability (可靠性和可用性)

可靠性和可用性是衡量服務是否符合商定的服務等級目標 (SLO) 的兩個重要指標。

可用性的測量由時間損失驅動，而故障的頻率和影響驅動可靠性的測量。可用性和可靠性至關重要，因為它們使利益相關者能夠評估服務的健康狀況。

可靠性 (R) 和可用性 (A) 是兩個不同的概念，但它們是相關的。在數學上，A 是 R 的函數。這意味著 R 的值可以獨立變化，而 A 的值取決於 R。因此，我們可能會遇到以下情況：

低 A，低 R
低 A，高 R
高 A，低 R
高 A，高 R (理想)
