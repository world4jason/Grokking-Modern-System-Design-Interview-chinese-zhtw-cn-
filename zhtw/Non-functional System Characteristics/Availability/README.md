# Availability (可用性)

## What is availability? (什麼是可用性？)

### Measuring availability (測量可用性)
在數學上，可用性 A 是一個比率。A 值越高越好。我們也可以把它寫成一個公式：

A (百分比) = (總時間 - 服務宕機時間)/總時間 * 100

## Availability and service providers (可用性和服務提供商)
每個服務提供商可能會在不同的時間點開始測量可用性。一些雲提供商在首次提供服務時開始測量，而另一些則在特定客戶開始使用服務時進行測量。如果服務並非對所有客戶都宕機，一些提供商可能不會降低其報告的可用性數字。計劃內的停機時間不包括在內。由於網絡攻擊導致的停機時間可能不會納入可用性計算中。因此，我們應該仔細了解特定提供商如何計算其可用性數字。
